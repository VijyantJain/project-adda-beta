# Project Adda — Master Product Blueprint
Updated: 2026-09-22

## 1. Vision
Build a social playground for real people who already know each other, with a later public discovery layer. The product should make ordinary friend-group downtime interactive: questions, choices, predictions, reactions, photos, plans, inside jokes, status and conversation.

The working name "Adda" is temporary.

## 2. Core promise
Open Adda because:
- something about you or your people changed;
- there is something quick to answer/react to;
- your personal Vibe can progress immediately;
- a Crew reward/reveal is getting closer;
- someone interacted with you;
- public Arena has always-available content aligned with your interests.

## 3. Core entities
### Profile / Vibe
Public/private identity surface. Vibe level, streak, badges, signature, reputation and selected activity.

### Crew
Private persistent social space for a real-world group.

### Drop
Atomic interactive object. Current types: Quick Answer, Most Likely, This/That, Vote, Rate, Predict.

### Reveal
Payoff generated by answers/activity.

### Daily Deck
Personal personalized set of small actions. Designed to create an immediate solo loop even when friends are inactive.

### Vibe Capsule
Variable personal reward earned through Daily Charge/progress. Rewards can be cosmetic/status/collection/progress—not money or gambling.

### Crew Pulse
Group activity meter that powers Mystery Reveals.

### Moment
24-hour ephemeral post: photo/text first; short video later.

### Blink
View-once/disappearing media primitive for private messaging/Crew contexts.

### DM
1:1 private conversation.

### Arena
Public rolling personalized feed.

### Plan
Crew coordination object: date/time/options/RSVP.

### Memory
Pinned or archived Crew artifact: reveal, Moment, inside joke, event, recap.

## 4. Personal retention engine — Daily Vibe Loop

First-session testbed: docs/FIRST_FIVE_VIBE_RUN.md. New visitors play five finite curated cards before being asked to create/invite; one-time Starter Vibe points and trophies build early momentum; a Bonus Five is optional. The real daily repeating supply below is a FUTURE design, not shipped by First Five v1.
The personal loop must not depend on Crew participation.

Loop:
1. Open app.
2. See today's Daily Deck / personal mission.
3. Complete a 3–15 second action.
4. Receive immediate Vibe/Charge feedback.
5. Progress streak/level/badge.
6. Every N meaningful actions opens a Vibe Capsule.
7. Capsule reveals a variable but non-monetary reward:
   - cosmetic shard/theme
   - badge progress
   - profile effect
   - interesting factual personal stat
   - mission wildcard
   - limited event collectible
8. Capsule immediately exposes the next actionable card.
9. User can Flex/share meaningful status externally.

Supply priority:
1. unanswered items from own Crews
2. direct interactions/replies
3. friend/following content
4. Arena personalized content
5. system prompts/challenges

This prevents the loop dying when a Crew is quiet.

### Design guardrails
- reward meaningful actions, not empty taps
- no cash-equivalent random reward
- no deceptive countdowns
- streak loss should not punish excessively
- optimize return + meaningful participation, not pure screen time
- allow notification/streak controls

## 5. Group retention engine — Crew Pulse + Reveal Chain
Crew activity fills Pulse.
Meaningful actions have weighted contribution.
At milestones, unlock Mystery Reveal based on real Crew interaction patterns:
- biggest agreement/disagreement
- unexpected self-vote
- prediction winner
- most-picked mate
- strongest This/That match
- fastest responder
- funniest split
- most active pair

Reveal immediately leads to next Drop/challenge. Weekly Pulse can reset while history remains in Recap/Memories.

## 6. Social identity & graph
### In-app
Every visible name/avatar is interactive and opens Vibe profile.
Examples: mates, voters, respondents, chat senders, leaderboard, Moment viewers, DM participants, Arena creators.

### External
Shareable profile link opens public Vibe directly with zero friction.

### Privacy modes
- public profile
- private profile requiring accepted follow
- Crew-visible identity
- per-content audience controls

Future social graph:
follow, requested-follow, accepted private follow, shared-Crew connection, block, mute.

## 7. Moments / Stories
24-hour ephemeral surface because short-lived visual sharing is a proven social behavior.

V1:
- image + text
- audience: one Crew / all Crews / accepted followers / custom circle
- viewer list
- emoji/reaction
- reply -> DM
- save own Moment to Memories optionally

V2:
- short video
- music/stickers/captions
- highlights if user explicitly saves
- story chains/events

## 8. Disappearing media — Blink
View-once private image, later video.

Rules:
- explicit "view once" marker
- media stored in dedicated ephemeral storage
- signed short-lived URL
- mark consumed after successful open
- short grace period for load failure
- optional one replay policy
- TTL cleanup job deletes expired/consumed objects
- sender sees opened state
- no promise of screenshot prevention on web; native clients can use platform signals where available but cannot guarantee prevention
- report/block available before deletion metadata expires

## 9. DMs
V1:
- 1:1 text
- emoji
- share Drop/profile/Moment
- reply to Moment
- requests for people without mutual/shared context
- accepted-follow/shared-Crew shortcut
- block/report/mute
- read status optional

V2:
- image
- Blink
- voice notes
- short video
- reactions/reply/thread
- typing/read controls
- group DMs only if user demand is clear

## 10. Arena
Arena is the public rolling feed and always-available interaction supply.

Content candidates:
- public Drops
- public creator/profile content
- public Moments
- trending cultural prompt packs
- limited event challenges

Ranking inputs (non-sensitive):
- answered/created Drop categories
- explicit likes/hides/not-interested
- follows
- shared Crews/context
- language
- coarse region only where useful
- recency
- novelty
- creator diversity
- interaction history

Ranking objectives:
- probability of meaningful answer/reaction/create/follow/share
- return-quality signal
- diversity and novelty
- safety
Do not optimize solely for dwell time.

Cold start:
- optional lightweight interest selection
- first 10–20 Arena interactions rapidly adapt interest weights
- exploration bucket prevents filter bubble lock-in

## 11. Plans
Crew object:
- title
- date/time
- location/link
- RSVP
- choice poll
- reminders
- comments/Drop thread
- post-event Moment/Memory creation

## 12. Memories & pinned inside jokes
Permanent Crew layer:
- pin Drop/Reveal/Message/Moment/Photo
- automatic Recap candidates
- event collections
- inside-joke labels
- anniversary resurfacing
- user-controlled deletion/privacy

## 13. Templates / Remix
Every popular Drop can be remixed.
Template sources:
- Adda system decks
- seasonal/cultural packs
- trending Arena Drops
- Crew history
- creator templates
One tap should prefill format/question/settings while avoiding accidental attribution copying.

## 14. Notifications
In-app first, push later.
High-value notification taxonomy:
- someone picked/mentioned you
- reply/DM
- Reveal unlocked
- 1 action left for Capsule
- streak at risk (opt-in)
- badge/level unlocked
- Crew Pulse close to reward
- Moment reply
- Plan reminder
- follow request
Rate-limit aggressively.

## 15. Home
Eventually Home should prioritize "things waiting for you":
1. Daily Vibe Loop / next personal action
2. direct interactions
3. Crew activity needing response
4. unlocked Reveals
5. active Plans/Moments
6. recommended Arena cards

## 16. Safety and trust
- 18+ launch
- private-by-default Crews
- report/block/mute
- message requests
- audience controls
- content moderation
- rate limits
- abusive-account handling
- no sensitive/protected-trait inference
- no attractiveness ratings
- no public stranger DMs by default
- explicit ephemeral-content policies
- transparency around data collection

## 17. Growth loops
- Drop deep link -> answer -> Crew exploration
- Vibe profile/card -> external share -> profile -> Adda
- Reveal card -> share -> exact Crew/Drop context
- Moment share/reply -> DM/profile
- template/remix -> creation
- Arena -> profile/follow/Crew/Drop
- events/campus/community packs

## 18. Business model candidates

Future gifting (not implemented): free supportive social gifts and paid cosmetic gifts are concepts. Purchased items should not directly substitute for earned experience; preserve fairness and protect against reciprocal point farming. Canonical detail: docs/REWARD_ECONOMY.md.
Only after retention:
- cosmetic Vibe/profile themes/effects
- Crew themes and premium admin/insight tools
- event/campus/brand packs
- creator tools
- premium storage/highlights
- partnerships
Avoid intrusive advertising until user value and retention are proven.

## 19. North-star and health metrics
Candidate North Star: Weekly Meaningful Social Actions per retained user / retained Crew.

Supporting:
- D1/D7/D30 retention
- sessions per retained user
- distinct Drops answered
- creation rate
- share rate
- Crew weekly active ratio
- DM reply rate
- Moment posting/reply rate
- Daily Deck completion
- Capsule unlock rate
- Vibe streak continuation
- Arena meaningful-action rate
- hide/report rate
- crash/error rate
- time-to-first-value

## 20. Principle
Adda should feel alive because people and identity matter—not because the product merely maximizes endless scrolling.


## v0.6.1 first-session conversion and Home
Two different first-time cohorts now share one reward engine. Direct visitor plays, collects genuine milestones and receives only a seeded-Crew creation CTA at Tenacious; invited newcomer joins provisionally then plays before entering the original invited Crew or Drop. The trophy stage uses the precise neon reference cropped from the user's screenshot with flashes/particles. No first-timer is intentionally routed through the unrelated generic empty-Crew creator.

Current Home is a genuine personalized Crews/Vibe dashboard, not a fake public feed. Future Home “For You” mixes real replies, friends' Crews/Moments, next personal mission and selected Arena recommendations, while Arena remains its own rolling public content/discovery surface.

Account/auth/profile/contact progression is documented in ONBOARDING_IDENTITY_CONTACTS.md. Real email/mobile OTP, unique @handle, photo, bio and contact sync are not shipped in Netlify field test; they need identity/auth/permissions and privacy work in M1+.


## M0.7 first-use guide / content experiment
New browser v2 Starter cards use six mass-relatable questions including explicit interest selection, then two cards drawn from one of seven private interest packs, then two universal identity/crew cards; legacy v1 unchanged. After first Crew entry, two more PRIVATE preference picks, two real SHARED Crew answers, sequential coach marks across Home/Crew/+/Vibe/Profile and guided local profile. Full guided signup is the future end-state and remains awaiting real OTP/provider.
Gender is optional secondary input for user-selected content, never a proxy for inferred interests or a barrier. All private picks stay outside Crew aggregates; common shared Crew Drops and results are the same for all its mates. Continue reward loop on genuine progress, one-time server-side points, explicit user choice and reasonable skip controls.
See FEATURE_SPEC_CHECKLIST.md and ONBOARDING_M07_SRS.md.

## v0.7.1 / v0.8 cold-start thesis
Founder-observed behaviour: testers completed Tenacious and sent a trophy screenshot as if the product ended. Required group creation/invites after ten created premature responsibility before social value. New direct-user contract: Starter progress → personal Aura → optional identity/customization → voluntary Crew. Invitation cohort instead gets exact linked social object. A person without active friends requires a genuine finite personal engagement supply (Daily Aura Deck, V-015) and good next-action design; Starter is not a daily product. Hypotheses to test: solo return frequency, profile investment, voluntary first Crew, invite acceptance, second member real replies; no false social proof or coercive reward patterns.

## v0.7.2 first-session contract
A Starter trophy is the start of a personal product identity, not the end of a quiz or mandatory instruction to recruit. The first Aura page must prove the actual previously earned points and show why a person builds, earns and can share that progress over time. A guided solo path must introduce the actual product areas without inventing Crew mates and conclude with a local optional-avatar profile; social participation naturally follows when someone wants another real person to answer. A reliable meaningful solo loop still needs v0.8 Daily Aura Deck and is NOT delivered solely by an Aura score page.
