## Photographic and animation upgrade — open acceptance requirement D-020
Before a wider campaign, produce/commission/license high-quality *actual* scene images for at least the ten common prompts plus fourteen personal pack variants, each with individually consistent 9:16 and 16:9 crops. Prefer own generated or properly licensed photos with source manifest; protect trademarks, identifiable people and rights of publicity. Include per-scene prompt/image hash/author/license/date/crop/alt text and no repeated unrelated clips. Store bundled optimized AVIF/WebP locally with SVG fallback to avoid third-party loading failures and unnecessary analytics leakage. Target mobile decode <200 KB per card wherever visually acceptable, prepare original large master outside repo. Use restrained animated sparks/zoom that does not obscure choices and respect prefers-reduced-motion.

The full-size source files were NOT generated by the last code updates; artwork work remains IN_PROGRESS in FEATURE_SPEC_CHECKLIST.md. Never call generic SVG placeholders “realistic lifestyle photography.”
